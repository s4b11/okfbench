# Roadmap Ideas and Demo Takeaway

Possible next steps include mobile clients, stronger risk models, multi-clinic tenancy, a parent helper chat, richer analytics, and electronic health record connectors.

The takeaway for this open-source showcase is simple: structured concept knowledge (OKF) and longer narrative docs (BM25 corpus) can answer the same Infant Guard questions with different retrieval behavior, while the UI logs latency and sources for side-by-side comparison.

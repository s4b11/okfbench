# Infant Guard Demo Introduction

Infant Guard is a fictional portfolio demo: a web application for K Brother Children's Hospital that helps clinicians, parents, and staff coordinate newborn care. Families and care teams share growth notes, immunization reminders, nutrition plans, and visit schedules in one place.

The showcase emphasizes fewer missed follow-ups, clearer handoffs, and clinician-reviewed nutrition suggestions. A Python web backend and a relational database keep structured records available for dashboards and notices.
